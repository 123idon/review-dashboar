3. 경쟁사 동향

명가삼대떡집 대시보드 실측

  • 누적 132,090건 · ★4.9. 별점 5점 89% / 4점 10%로 4점 비중이 자사(3%)보다 높음 → 만점 편중이 자사보다 덜함 실측.
  • 최근 7일 신규 642건 — 자사(94건)의 6.8배. 현재 가장 빠르게 후기(=판매)를 쌓는 경쟁사.
  • 주력: 쑥떡·쑥인절미(19,820) / 콩달떡(14,555) / 쑥설기(11,197). 쑥·팥 기반 전통 라인이 강함.
  • 웹: 공식몰·쿠팡·신세계몰 다채널 운영, Threads·TikTok·Instagram 활발. "쑥인절미+콩고물 증정" 등 증정형 프로모션 상시 사실.

창억떡 리뷰 데이터 확인 불가

  • 대시보드 미연동(자사몰 로그인 필요, 스마트스토어 연동 준비 중) — 정량 리뷰 수집 불가.
  • 웹: 2026년 3월 SNS 바이럴(하말넘많 유튜브 언급, DAY6 영케이 콘서트에서 호박인절미 언급)로 급부상 사실.
  • NS홈쇼핑 특집방송 편성, 마켓컬리·쿠팡 냉동떡 유통, 이마트몰·SSG 입점 사실.
  • 시사점: 냉동 유통 + SNS 바이럴로 선물 수요 관심을 흡수 중 추정. 자사 당일생산 원칙과 정반대 전략.

압구정공주떡집 리뷰 데이터 확인 불가

  • 웹: 흑임자인절미 시그니처, 강남 신사동 입지, 친환경·약재 재료 강조. 당일 생산·당일 소비, 홈페이지/전화/방문 주문 사실.
  • 온라인 대량 유통·리뷰 규모 데이터 없음. 프리미엄·로컬 포지션으로 자사와 직접 경쟁 강도는 상대적으로 낮음 추정.

"선물로"가 긍정 상위 키워드에 위치 → 선물용 포지셔닝은 리뷰에서 검증됨. 부정 키워드는 특정 이슈 집중 없이 분산되어, 구조적 품질 문제보다 개별 배송·기대차 이슈로 보임 추정.

2026 떡 시장 트렌드 (웹 검색) 사실

  • 떡류 국내 판매액 2024년 9,291억 원, 6년 새 65% 급성장, 연 5~7% 성장세(이투데이·PwC 보고 인용).
  • "두쫀쿠" 유행으로 쫄깃 식감 선호 강화 + 건강 소비 결합. 버터떡(상하이발), 얼먹젤리 신흥 디저트 부상.
  • 분홍모자떡 등 SNS·캐릭터형 떡이 20~30대 여성 중심 확산.
  • 시사점: 시장은 성장 중이나 성장 동력이 SNS 바이럴·식감·비주얼로 이동. 자사 강점(전통·명인·특허)과 트렌드 축이 어긋나 있어, 신규 유입 열세의 배경 추정.

5. 이번 주 액션 아이템

우선순위 1: "주간 신규 리뷰 94 → 명가삼대 수준 회복"이 이번 분기 단일 핵심 지표. 누적 자산이 아니라 신규 유입 속도를 봐야 한다.
#액션기대효과기한
1구매 후 리뷰 유도 강화(자사몰·네이버). 리뷰 작성 시 즉시 혜택 → 신규 리뷰 유입 속도 회복신규 리뷰↑즉시
2파파공방(현미 건강라인) 신규 유입 0건 원인 점검 — 노출 중단/재고/판매 종료 여부 확인정체 원인 규명이번 주
3대표 상품 쏠림(밥알찹쌀떡 41%) 완화 — 흑임자·쑥떡 리뷰/노출 별도 유도포트폴리오 균형2주 내
4창억떡·압구정공주떡집 대시보드 연동 준비(스마트스토어 등) — 경쟁 정량 사각지대 해소모니터링 완결1개월
5명가삼대 벤치마킹: 증정형 프로모션(+콩고물 증정류)·다채널 SNS(TikTok/Threads) 대응안 검토신규 유입 방어1개월
