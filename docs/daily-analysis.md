# 전일 후기 통계

2026-09-18부터 AI 해석을 중단했습니다. 서버의 분석 예약·시작 시 분석·분석 조회 경로를 제거하고 Railway DAILY_ANALYSIS_ENABLED=0을 적용했습니다.

전일 보고서 생성은 매일 오전 9시(한국시간)를 유지합니다. 모든 날짜에서 저장된 전체 후기 원문을 기준으로 브랜드·채널별 건수, 평균 별점, 별점 분포, 3점 이하 건수와 비율을 계산합니다. 평균과 비율의 분모는 유효 별점이 있는 후기입니다. 미제공 별점과 수집 불가 상태를 구분합니다.

통계는 화면과 한 장 PNG에 같은 방식으로 표시합니다. 기존 후기 선정과 본문 표시, 과거 날짜 조회, 원본 보존은 유지합니다. 기존 AI 모듈과 저장 결과는 기록으로 남아 있지만 운영 서버에서 호출하거나 표시하지 않습니다. 추가 API 토큰을 사용하지 않습니다.
