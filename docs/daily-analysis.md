# 전일 후기 해석

- Railway 서버가 한국시간 09:05에 전일 종합의 **선정 후기만** 분석합니다. PC는 필요 없습니다.
- 모델: `gpt-4.1-mini-2025-04-14`. 환경변수 `OPENAI_API_KEY`, `DAILY_ANALYSIS_ENABLED=1`로 활성화합니다.
- 입력은 브랜드, 평점, 선정 본문뿐이며 작성자/이미지/주문 정보는 보내지 않습니다. 본문 연락처·이메일은 가립니다.
- 출력: 요약, 브랜드별 의미, 확인할 업무, 원문 인용. 인용이 해당 브랜드/후기 본문에 없으면 결과를 거부합니다.
- 과거 추세나 전체 고객의 의견 비율을 추정하지 않습니다. 건강효능이나 제품불량 원인도 확정하지 않습니다.
- 데이터는 영구 볼륨의 `daily_analyses/YYYY-MM-DD.json`에 저장합니다. 원문 보고서는 변경하지 않습니다.
- `daily_analyses/runs/UTC날짜.json`을 호출 **전**에 배타적으로 생성합니다. 재시작·새로고침·동시 실행·실패로 중복 호출하지 않습니다.
- 하루 UTC 기준 한 번, 입력 UTF-8 60,000바이트 이하, 출력 2,500토큰 이하. 자동 재시도/다른 모델 전환 없음.
- 빈 선정 결과는 API 없이 저장합니다. 09:05 이후 재시작하면 미완료 전일 분석을 1회 시도합니다.
- 화면 및 한 장 PNG는 저장된 분석을 같은 렌더러로 표시합니다. GET/이미지 저장은 API 호출하지 않습니다.
- 원문/선정 결과가 달라지면 해시 비교로 분석을 숨기고 재분석 필요 상태를 표시합니다. 과거 날짜에 분석이 없으면 없다고 표시합니다.
- 무료 토큰 등록은 별도의 OpenAI 설정입니다. 모델·공유 조건·조직 전체 무료 잔여량이 충족돼야 무료이며 이 코드만으로 무료를 보장하지 않습니다. 자동 충전은 사용하지 않습니다.
- 실패 시 공급자 오류 본문/키를 저장하지 않고 오류 유형만 기록합니다. 실패·제한·연결 전 상태에서도 원본 전일 종합은 정상 제공됩니다.
- 운영자는 일별 분석 JSON의 `usage`와 OpenAI Usage/Costs에서 실제 토큰 및 비용을 확인합니다.
